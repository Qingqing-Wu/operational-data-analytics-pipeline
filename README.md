# Operational Data Analytics Pipeline


## Overview
This project implements an automated Python–SQL data pipeline that centralizes warehouse operational records previously managed in Excel.

The pipeline supports incremental ingestion, cross-table SQL analysis, Power BI reporting, and downstream Python-based analytics and modeling, providing a reliable analytical foundation for operational insights.


## Data Sources
- Outbound records
- Inbound records
- Transfer records
- Value-added / custom operational records

## Pipeline Features
- Incremental ingestion
- Row-level unique keys
- Import logging with timestamps
- Cross-table SQL analysis

## Analytics Use Cases
- Power BI dashboards
- Operational reporting
- Python-based forecasting and modeling
